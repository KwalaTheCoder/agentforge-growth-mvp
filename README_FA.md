AgentForge Paid Radar v4 — بررسی رقابت و PR

فایل paid_opportunity_radar.py را در ریشه پروژه ویندوز جایگزین کنید. از نسخه قبلی بکاپ بگیرید. صفحه Streamlit فعلی بدون تغییر کار می‌کند.

discover() همچنان خروجی قبلی را تولید می‌کند و فیلد competition را اضافه می‌کند. برای حداکثر پنج فرصت با وضعیت Review manually، وضعیت Issue اصلی، assignee، یک صفحه از timeline و یک صفحه از کامنت‌ها بررسی می‌شود. در صورت یافتن PR ارجاع‌شده یا ادعای انجام کار، نتیجه Hold / verify می‌شود. عدم مشاهده شواهد، تضمین آزاد بودن پروژه نیست. درخواست‌های API محدود هستند؛ اگر API خطا دهد مقدار unknown می‌ماند. برای افزایش سهمیه API می‌توانید GITHUB_TOKEN را در تنظیمات برنامه وارد کنید، اگر رابط آن را پشتیبانی می‌کند.
